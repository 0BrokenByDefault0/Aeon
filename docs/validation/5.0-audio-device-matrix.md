# Aeon 5.0 audio and device matrix

## Automated environment and truth boundary

Audio unit and integration evidence ran in `AppTests` on iPhone 17 Pro and iPad Pro 13-inch (M5) simulators with iOS 26.5, Xcode 26.6 (17F113), and macOS 26.6.2 (25G83).

The integration graph deliberately reports a 48 kHz, two-channel mock speaker output so timing can be exact and deterministic. That proves scheduling, state, error classification, and recovery logic. It does not prove the active sample rate, route, resampling behavior, or bit transparency of a physical output. Aeon reports source format separately from negotiated output and makes no bit-perfect claim.

## Format and failure matrix

| Input | Automated result | Evidence / caveat |
| --- | --- | --- |
| WAV, PCM 16-bit stereo, 44.1 kHz | PASS | Exact source metadata and frame count; included in 44.1 → 96 → 48 kHz integration queue |
| WAV, PCM 16-bit stereo, 48 kHz | PASS | Exact source metadata/frame count and deterministic two-file PCM boundary fixture |
| WAV, PCM 16-bit stereo, 96 kHz | PASS | Exact source metadata and frame count; included in mixed-rate integration queue |
| M4A/AAC, 48 kHz fixture | PASS | Native probe classifies playable; compressed seek is checked to the selected source frame tolerance |
| MP3, 48 kHz fixture | PASS | Native probe classifies playable |
| FLAC, 48 kHz fixture | PASS | Native probe classifies playable |
| Ogg/Opus | CAPABILITY-DEPENDENT | Structurally valid fixtures resolve explicitly to playable or unsupported according to the OS decoder; malformed containers resolve to decode failure, never to a guessed capability |
| Missing file | PASS | Explicit unavailable-media failure; no playback begins |
| Corrupt/truncated known container | PASS | Explicit decode-failed result with a reason; no playback begins |
| Unsupported media | PASS | Explicit unsupported-media result; no playback begins |

## Integration behavior

| Behavior | Result | Automated evidence |
| --- | --- | --- |
| 44.1 → 96 → 48 kHz queue | PASS | Converted durations share one contiguous 48 kHz output timeline and hand off in order |
| Exact PCM boundary math | PASS | Following source is scheduled at the exact output frame; split 48 kHz fixtures have an exact expected concatenation |
| Compressed seek | PASS | M4A seek preserves the selected source frame within one 44.1 kHz frame |
| Queue replacement | PASS | Replaces prepared-next content while preserving the current track, position, and monotonic revision |
| Restore without autoplay | PASS | A persisted playing intent restores paused at the exact checkpoint; graph start count remains zero |
| Missing/corrupt/unsupported handling | PASS | Each unplayable class remains distinct and leaves playback stopped |
| Recovery escalation | PASS | Node, engine, then session recovery is attempted in order and resumes only from preserved playing intent |
| Real output capture | NOT RUN | Opt-in `AEON_RUN_AUDIO_CAPTURE=1` gate was skipped on each simulator; it requires an idle, actual 48 kHz route |
