# Aeon 4.2

Restores full-color planets while retaining the square monochrome interface. Planet surfaces now use spherical projection, directional light, atmospheric edges, seeded turbulence, mineral veins and fine terrain detail. Near worlds render at 640×640; distant worlds use smaller textures. The cache holds at most 24 detailed textures and upgrades at most one per rendered frame. Each world has a seeded reveal/touch signature within eight animation families; touch particles are capped at 192 and expire.

Cold launch opens a two-part mechanical spaceship door over the live sky. It supports immediate skip, reduced motion, and a timeout so initialization failure cannot leave the overlay blocking the app. Foregrounding does not replay the door.

Folder import: the old native button inferred directory-picker support from a DOM property. The native build now opens an explicit Files → On My iPhone → ISOLATION → Music → Scan workflow, prepares the Music folder, and also accepts compressed folder ZIPs with per-folder album grouping. Direct selection of arbitrary external folders is not added to the native shell. Desktop directory traversal now includes OPUS and adjacent artwork and reports non-cancellation errors. Scans prevent duplicate concurrent runs and surface folder read failures.

Validation: 39 unit checks, 125 browser regressions, 14 interface checks, 7 arrival/folder/world checks. Visual inspection of the door and all eight world surfaces. Native Files behavior is tested through the existing Filesystem mock; physical iPhone validation remains outstanding.

Packaging uses the existing unsigned Capacitor native executable/frameworks, unchanged byte-for-byte. Updated web assets and bundle version 4.2/build 42; app.isolation.sky retained. This is not a fresh Xcode build. Arthemys font import from 4.1 remains; the actual font is still not bundled. Cumulative patch base: 849a1dbbdf66b37491964b54470241920fc6d9e3. GitHub write access was unavailable in prior releases; deliver source patch with IPA.
