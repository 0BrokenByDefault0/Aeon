# Aeon 4.0

A collection-first interface: artwork and compact library views, a listening card, redesigned album and player screens, and simplified navigation. Adds saved-position resume, persistent layout/sort preferences, and track actions for Play next, queue, playlists, and renaming. Duplicate sheet opens are ignored. Local system fonts replace network font requests.

Validated with 39 unit tests, 125 browser regression checks, and 11 interface checks covering real PCM playback, reload/resume, queue edits, and narrow screens including native safe areas. Physical iPhone interruption testing remains outstanding.

The delivered IPA updates web assets in the existing unsigned native shell from GitHub Actions artifact 9787045744 (source 849a1db). Swift and native dependencies are unchanged. Bundle identifier remains app.isolation.sky. Version is 4.0, build 40.

Repackage an unsigned base with:

```sh
python3 scripts/package-unsigned.py base.ipa Aeon-4.0-unsigned.ipa --version 4.0 --build 40
```
