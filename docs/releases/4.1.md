# Aeon 4.1

User-directed visual revision of 4.0. Sharp rectangular white borders, cool light gray panels at 98% opacity, white type, black sky and monochrome sky rendering. Removed interface color accents, rounded corners and glowing decoration, including the placeholder artwork. Existing playback, resume and queue behavior retained.

Arthemys is not bundled: no font file was supplied or available in the repository. The application requests locally installed Arthemys and otherwise uses Georgia/Times. Settings → Typography → Import Arthemys accepts OTF/TTF/WOFF/WOFF2, validates before persisting and restores the imported face at launch. Both DOM and canvas text use the imported face. The test uses a system serif fixture solely to validate import; this fixture is not packaged or represented as Arthemys.

Validation: 39 unit tests, syntax check, 15 interface checks including phone layouts, font rejection/import/restart and square panel borders. Physical iPhone testing remains necessary.

Packaging: existing unsigned native Capacitor executable and frameworks preserved byte-for-byte; web assets replaced; version 4.1/build 41; bundle app.isolation.sky unchanged. This is not a fresh Xcode compilation. Source remains local because GitHub write access was blocked in the prior release. Cumulative source patch base: 849a1dbbdf66b37491964b54470241920fc6d9e3.
