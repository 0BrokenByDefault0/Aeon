# Aeon 4.4

Silver-glass surfaces: main panels, player, dock and menu sheets use cool gray at 8% opacity (92% transparent). Inner controls use 4.5% opacity and selected controls 12%. Removed the opaque sky dimmer and dock gradient. Sheets hide underlying menu/panel text while retaining the sky, and restore the previous sheet on close. Black sky, vibrant planets, white text and square borders remain. The sky still pauses behind sheets to preserve playback/rendering efficiency; its last frame remains visible through the glass.

Bundled Aeon Nocturne, a reference-inspired custom display serif derived from Latin Modern Roman 17 with twelve new interlocking ligatures, nested OU/QU and an RA swash. This is not the original Arthemys font or an exact reproduction. The font is included offline and in the service-worker cache. Optional imported Arthemys still takes precedence. Licensing, attribution and reproducible font build script are included.

Validation: unit and browser/interface checks; specific assertions for font loading, actual OU ligature substitution, 8% sheet opacity, no sky dimmer and correct stacked-sheet visibility. Visual inspection of the full player. Physical iPhone testing remains outstanding.

Package: web assets and version 4.4/build 44 updated in the existing unsigned Capacitor native shell; app.isolation.sky and native executable/frameworks preserved. Native playback/direct native folder picker remain pending an Xcode build route. Source patch base 849a1dbbdf66b37491964b54470241920fc6d9e3.
