# Aeon 5.0

Aeon 5.0 replaces the visible Capacitor/WebView application with a native SwiftUI shell and moves playback authority into the native audio stack. The sky remains the ground beneath Library, Playlists, Settings, album, and player panels; catalogue, queue, backup, diagnostics, accessibility, and migration behavior now have native test coverage.

## Release scope

- Native SwiftUI root, adaptive iPhone/iPad chrome, Metal sky, Library, album editor/detail, playlists, Settings, player, queue, import, backup/restore, activity log, and diagnostics.
- Serialized native playback coordinator with gapless queue scheduling, seek/repeat/replay-gain/EQ state, lock-screen commands, interruption and route-loss policy, truthful source/output telemetry, and bounded recovery.
- Native catalogue and media ownership rules, stable sky coordinates and planets, streaming ZIP64 backup, transactional restore, and read-only migration from the existing Capacitor origin.
- Accessibility-sized layouts, semantic sky order, textual playback/HUD/error state, minimum targets, deterministic screen fixtures, and dark appearance under both system themes.

## Format, migration, and accessibility results

- WAV PCM at 44.1, 48, and 96 kHz passes native probing and mixed-rate scheduling. M4A/AAC, MP3, and FLAC fixtures probe as playable. Ogg/Opus is explicitly playable or unsupported according to the OS decoder; malformed Ogg remains decode-failed. See [audio and device matrix](../validation/5.0-audio-device-matrix.md).
- Empty, path-backed, blob-backed, mixed, interrupted, missing-file, bad-CRC/conflict, and 10,000-record migrations pass automated source-preservation and transactional-publication checks. The simulator also reads a seeded real `capacitor://localhost` origin end to end. See [migration matrix](../validation/5.0-migration-matrix.md).
- Native destination semantics, sky traversal order, selected planet state, HUD/player/error text, 44×44 targets, AX5 reachability, appearance overrides, both orientations, and deterministic screen captures pass on iPhone and iPad simulators. See [SwiftUI screen matrix](../validation/5.0-swiftui-screen-matrix.md).

## Packaging

Version is 5.0, build 50, bundle identifier `app.isolation.sky`. The unsigned IPA gate syncs Capacitor assets, compares both migration assets, installs pods, compiles a fresh Release `App.app` with signing disabled, checks that product exists, and packages only that just-built product under `Payload/App.app`. The IPA requires external signing before installation.

## Retained compatibility boundary

Capacitor pods and `app/legacy-migration.html` / `app/legacy-migration.js` remain solely to read legacy IndexedDB during the 4.x upgrade. The hidden migration controller is the only WebView path instantiated by the production SwiftUI root. The normal root and every visible/captured screen are SwiftUI, UI tests require zero visible WebViews, and the production root never loads normal `index.html`.

## Deliberate omissions

The handoff marked these as optional; Aeon 5.0 omits them without changing the release structure:

- Airlock overture
- Grain/glitch overlays
- Planet Drift playback
- User planet naming
- Planet jump-list fast travel
- Additional ceremonies beyond the implemented constellation/world banner
- Library recommendations card
- Album merge and manual track reordering
- iPad keyboard shortcuts beyond transport

The core non-blocking constellation/world ceremony layer, wider-framing Capture, and Activity Log are implemented.

## Known limitations and approval status

- Physical-device testing is **NOT RUN**: the connected iPhone was offline and no physical iPad was available. Speaker, wired/USB DAC, Bluetooth/AirPods, AirPlay, lock/background behavior, interruptions, route removal, Control Center/hardware commands, real mixed-rate output, import, migration, rotation, sustained playback, actual VoiceOver speech/focus, and physical visual review remain unobserved.
- The real-output PCM capture gate is opt-in and was skipped on both simulators. Automated audio uses a deterministic 48 kHz mock output; no physical output rate or bit-perfect claim is made.
- Ogg/Opus playback depends on the decoder available from the running OS and is surfaced as an explicit playable/unsupported capability.
- The inherited 4.6.1 browser-interface oracle remains nonzero for its pre-existing overflow/safe-area assertions; the reference remains untouched.
- The package is unsigned and cannot run until signed by a valid distribution or sideloading workflow.

This is a clean source, automated-test, and fresh-package checkpoint. Because every physical row is still **NOT RUN**, it is not physical-device release approval.
