Aeon Nocturne Regular, version 4.4. Modified and maintained for the Aeon application.

Derived from Latin Modern Roman 17 Regular, by Boguslaw Jackowski and Janusz M. Nowacki, based on Donald E. Knuth's Computer Modern. Source family: https://www.gust.org.pl/projects/e-foundry/latin-modern

Changes: renamed font family and PostScript identifiers; added twelve custom interlocking capital and ascender ligatures, nested OU/QU forms, and an RA swash. Inspired by the supplied high-contrast serif references; this is not the original Arthemys font.

Reproducible build: scripts/build-nocturne-font.py in the Aeon source repository. The source LM font is unmodified; the output is a separate derived face.
